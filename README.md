# BreakoutIQ

BreakoutIQ is a machine learning baseball analytics
project designed to predict future MLB hitter performance
and identify potential breakout players.

## Goals
- Collect and analyze historical MLB Statcast data
- Identify statistical indicators of future improvement
- Train and evaluate machine learning models
- Build an interactive baseball analytics platform

## Tech Stack
- Python
- Pandas
- Scikit-learn
- PyBaseball
